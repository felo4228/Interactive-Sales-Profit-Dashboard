# 📊 Interactive Sales & Profit Dashboard

An interactive dashboard built with **Python + Streamlit** to analyze **sales and profitability** of an online business using a CSV dataset.

This project covers the complete **Data Analysis / Business Intelligence workflow**:
- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Interactive visualizations
- Business KPIs
- Dynamic filtering

---

## 🚀 Local Demo

The application runs locally using Streamlit and opens automatically in the browser.

```bash
streamlit run app.py
